# Wolso Admin

Внутренняя веб-панель для команды Wolso: управление пользователями и
вакансиями, финансы/выплаты, роли и права, аудит-лог.
Отдельное приложение от Telegram Mini App в `../src` — свой стек, светлая
тема под десктоп.

## Стек

React 19 + TypeScript + Vite, Tailwind CSS v4, Zustand, React Router
(Hash Router), Framer Motion.

## Бэкенд и вход

Общий воркер с мобильным приложением — `../worker`, инструкция по
деплою в `../worker/README.md`. Локально нужен `.env` (см.
`.env.example`): `VITE_API_URL` и `VITE_BOT_USERNAME`.

Вход — через Telegram Login Widget (`src/screens/Login.tsx`), пускает
только приглашённых сотрудников (таблица `staff` в D1). Первый Owner
бутстрапится автоматически при первом входе с `OWNER_TELEGRAM_ID`,
заданным воркеру как секрет — дальше он приглашает остальных из
раздела «Пользователи» (нужен их numeric Telegram ID, не email).

## Роли и права

Роли и матрица прав приходят с бэкенда (`GET /admin/roles`) — 4 системные
роли (Owner/Админ/Модератор/Поддержка) сидятся миграцией, плюс можно
создавать свои («+ Своя роль» на странице «Роли и права»).
`src/components/layout/nav.ts` строит боковое меню по правам текущей
роли, а не по хардкоду ролей — новая кастомная роль автоматически
получает правильный набор пунктов меню.
