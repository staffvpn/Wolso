# Wolso Admin

Внутренняя веб-панель для команды Wolso: модерация вакансий и документов,
управление пользователями, финансы/выплаты, роли и права, аудит-лог.
Отдельное приложение от Telegram Mini App в `../src` — свой стек, светлая
тема под десктоп.

## Стек

React 19 + TypeScript + Vite, Tailwind CSS v4, Zustand, React Router
(Hash Router), Framer Motion. Данные — детерминированные моки в `src/data`,
как и в мобильном приложении: экраны и сторы ничего не знают о том, что
за ними мок, а не реальный бэкенд.

## Роли и права

`src/data/permissions.ts` — 4 системные роли (Owner/Админ/Модератор/
Поддержка) и матрица из 8 прав. `src/components/layout/nav.ts` строит
боковое меню по правам текущей роли, а не по хардкоду ролей — новая
кастомная роль («+ Своя роль» на странице «Роли и права») автоматически
получает правильный набор пунктов меню и раздел «Роли и права» умеет
редактировать её права прямо в таблице.

Внизу сайдбара — переключатель пользователя (только для демо): позволяет
посмотреть панель глазами любого члена команды и увидеть, как меню и
доступные действия меняются вместе с ролью.
